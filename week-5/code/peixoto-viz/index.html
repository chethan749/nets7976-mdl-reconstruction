Week 5 · Network reconstruction using the minimum description length principle

How many edges does the data pay for?

A network with N nodes has N(N−1)/2 possible edges. Maximum likelihood switches on all of them, because a tiny weight always fits the noise a little better than a zero. Peixoto's answer is to count bits: an edge stays only if writing it down costs less than it saves in describing the data. Everything on this page is recomputed in your browser from a simulated time series on Zachary's karate club, the network of the paper's Fig. 1.

  1. L1 regularization gets zeros by shrinking every weight, so sparsity and accuracy fight (§1).
  2. A prior density on real weights is not a description length, so MAP can't choose the sparsity (§2).
  3. Quantize the weights and let a hierarchy of discrete priors learn the weight distribution (§3).
  4. The result is no longer convex, so fit it with greedy moves that each lower Σ (§4–6), and check it (§7).
  5. The fitted model is a generative model: on modular networks its states split into macrostates (§8).

A density is not a code length

§IV · Eqs. (12)–(19) · footnote 58
Σ(X, W) = −log P(X | W) − log P(W)needs P(W) a probability massthen Σ is a number of bits

MDL reads −log P(X, W) as the length of a message: bits for the data given W, plus bits for W. That only works if P(W) is a probability. A density p(w) can exceed 1, so −log p(w) can be negative. Its value also changes if you change units, since p(w) does but the model doesn't. To get a real code you have to say how precisely each weight is written down: round it to a grid of step Δ. Then each value has probability ≈ p(w)·Δ, and precision costs log(1/Δ) bits per weight.

Cost of writing down one weight

Laplace density −log₂ p(w | λ), Eq. (18), vs. the quantized mass −log₂ P(w | λ, Δ), Eq. (19). Below 0 bits is not a code length.

What MAP over λ prefers

Σ in bits on your data, for the true weights and for the empty network, as λ varies. Dots: each line's minimum.

With the density, the empty network wins once λ is large enough. Each zero weight sits at the peak λ/2 of the Laplace density, and that peak grows without bound. So jointly maximizing over W and λ sends λ → ∞ and W → 0, which is why λ can't be learned by MAP and needs cross-validation. With quantized weights and an explicit adjacency matrix A, a zero costs only its share of log C(N(N−1)/2, E) bits, the empty network's Σ is bounded, and the true network keeps its lead at every λ. The MDL prior: let the weights choose their own distribution

§IV · Eqs. (15)–(27)
E ~ uniformpick pairs A | E uniformK, z_k z_k ~ quantized Laplacecounts m W_ij = z_{k(ij)}every level discrete

The paper builds the prior in levels. First the number of edges E, then which pairs they are (A). Then, instead of one Laplace draw per edge, a small set of K distinct values z_k (the weight categories). Each edge takes one of them, with category counts m_k drawn uniformly. Summing out the category probabilities gives the closed form of Eq. (27). Each nonzero weight now costs about log K bits instead of log(1/Δ). Precision is paid once per category, not once per edge. Below are draws from each prior, with λ = 10 so the weights are on the karate scale.

Compare the "bits for W" tiles. The density gives a negative number: an infinitely precise real number can't be sent in fewer than zero bits. The quantized Laplace pays roughly log₂(1/Δ) per edge. The hierarchy pays about log₂ K per edge, plus around 27 bits per category for its value. Shrinkage hasn't vanished, but it now acts only through the K category values, a small part of the total.

Fitting it: greedy moves that lower Σ

§V · Eqs. (28)–(29) · merge-split moves of Ref. [64]
W = 0, z = ∅sweep edges, then categories Ŵ = argmin Σ(X, W)nonconvex · accept only if Σ drops

The prior is no longer convex, so the paper replaces the LASSO solver with a set of moves. Each move is tried and kept only if it shortens the description. One sweep runs through all of them, and the fit stops when a few sweeps in a row change nothing. Press play to watch the fit on your data. The fit uses fast deterministic steps; §5 takes the moves one at a time and runs each exactly as the paper does.

Greedy moves overshoot, then MDL cleans up. In the first sweep each visited pair tries one of its options at random. For an empty pair that is "new category" half the time, which is accepted whenever the edge saves more than the ≈ 27 bits its own value costs, so K shoots up. Pairs that are only indirectly correlated also get in while the true paths between them are still missing. Once the true edges are in, those spurious edges no longer pay for themselves and are removed, and merges fold the one-edge categories together. The bits for W (orange) fall while the data bits saved stay level. With the default settings the fit ends with all 78 true edges, no spurious ones, in a single category.

Inside a sweep: each move, as the paper runs it

§V · Eqs. (28)–(29) · random bisection, Ref. [63] · merge-split, Ref. [64]
one state of the fitpropose one move ΔΣ(x) for every value x the move could takerandom bisection keep it only if ΔΣ < 0exact ΔΣ at every probe

Pick a move and a state of the fit, and the page proposes one move of that kind, exactly as §V describes it. For moves that choose a value, the grey curve is the full 1-D problem: the exact change in description length ΔΣ for every value the move could pick. The search never sees that curve. It only evaluates ΔΣ at its probes (numbered circles), keeping a bracket (shaded) that contains the best point found so far (black dot). Random bisection draws each probe uniformly inside the bracket, where a deterministic search would always take the same golden-section point. The move is kept only if the value it ends on gives ΔΣ < 0.

What the randomness buys, and what it doesn't. Along one weight, the Ising log-likelihood is concave and λ|w| is convex, so the continuous searches (a new value, a category value, a merged value) have a single minimum, and random and deterministic searches agree: try "Repeat" on one. The discrete choice of an existing category can have several dips, because joining a big category is cheaper for the prior (the log m_k! terms) while the data prefer the nearest value. Click Find a pair with several dips, then Repeat. The deterministic search lands in the same dip every time; random searches end in different ones, so over repeated sweeps the best one is eventually found and kept. That is the sense in which random bisection "eventually succeeds" (Ref. [63]). It is not a guarantee of the best overall W: the moves change one or a few entries at a time, and §V claims a good optimum, not the global one. No derivative is used in any of these searches; gradients appear only in Eq. (29), to rank candidates before any category exists.

What the categories buy

§IV, discussion after Eq. (27)
the fitted edges, fixedforce K Σ(K) = data bits + bits for Wvalues re-searched for each K

Keep the edges the fit found, but force them into K categories (1-D k-means, then the best value for each). More categories fit the data a little better and cost about 27 bits each, plus the cost of saying which edge has which. The fit's own K is wherever this curve bottoms out. With the paper's near-equal weights that is K = 1. Switch the top bar to two strengths and the minimum moves to 2. With spread out it lands where extra resolution stops paying for itself.

Fitted vs. true weights

No shrinkage, and no noise fitting. A category's value is set by the likelihood of all its edges together, with only a λ|z| ≈ 0.2-nat nudge from the prior, so the MDL weights land at the true level. L1 fits every weight separately, so its dots scatter vertically: that spread is noise being described edge by edge. Move the §1 slider to the λ that gets E right and the whole orange cloud drops well below the diagonal.

MDL errs toward too few edges, the others toward too many. With little data MDL returns a sparse network, because it can't yet afford more. The normal prior, even though it is the true one, overfits at small M: each edge placed at the mode collects the density's bonus of log(1/(√(2π)σ)) ≈ 3.7 nats, a "negative cost" of exactly the kind §2 warns about. L1 with cross-validation keeps about three times too many edges at every M, and its binary similarity doesn't improve with more data.

Macrostates: broken replica symmetry

§VI.A · Eqs. (35), (38) · Fig. 8(a)
P(x | W, θ) = e^{Σ W_ij x_i x_j + Σ θ_i x_i} / Zstrong, modular W P(x | W, θ) = Σ_α P(x | α) P(α)islands the dynamics can't leave

A reconstructed network is also a generative model, which is what the paper uses to predict interventions. On a modular network with strong couplings, the equilibrium Ising distribution (Eq. 35) falls apart into islands of high probability separated by valleys of low probability. Dynamics started on one island stays there for a time that grows exponentially with N, so what you would actually observe is P(x | α) for one macrostate α, not the whole mixture. Here eight replicas of one toy model (five modules of twelve spins, all +1 inside a module, a few ±0.6 couplings between modules, θ = 0) run the same heat-bath dynamics from random starts. The overlap q = (1/N) Σ_i x_iᵃ x_iᵇ between two replicas measures whether they ended up in the same place.

Same W, different answers. At weak coupling every replica explores the same distribution, q ≈ 0 for every pair, and P(q) has one peak. Past the transition (β ≈ 1/11 in mean field for modules of twelve, a little higher here) each module commits to a sign and stays there. Replicas freeze into different patterns, switches stop, and P(q) splits into peaks at ±1, ±0.6 and ±0.2: two replicas agreeing on 5, 4 or 3 of the 5 modules. Each frozen row is one term of Eq. (38). The keystone analysis (Eqs. 39–41) asks which single knockout pushes a system off its island. In this toy the modules are identical and θ = 0, so the islands are equally likely. In the inferred microbiome model, heterogeneous and mostly negative couplings between modules make P(α) uneven.

What this page leaves out

§V.B–D, §VI

Community structure (§V.B). Replacing the uniform P(A | E) by a degree-corrected SBM gives modular networks shorter descriptions, which regularizes further. Fitting it adds merge-split moves on the node partition (Ref. [64]). Node parameters (§V.C) such as Ising fields θ_i get the same quantized treatment, Eq. (34), with zero allowed. They are fixed at zero here. Empirical cases. The paper then reconstructs the Brazilian congress votes and the microbiome networks, where an L1 comparison is infeasible. On the microbiome it uses the fitted Ising model to predict which species' removal tips the system into another macrostate (§8 shows what a macrostate is).

Implementation notes: kinetic Ising likelihood, exact, θ = 0. MDL uses λ = 1, Δ = 10⁻⁸ as in the paper, starts from the empty network, and runs a fixed sequence of moves rather than the random order of graph-tool. L1 is cyclic coordinate descent with a proximal Newton step per entry, on a grid of 28 λ values, warm-started from large λ down. The reference C++ implementation is in graph-tool.
